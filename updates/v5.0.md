## Highlights
* **macOS**{: .label .label-green } **DirectX graphics support for Windows** Modern accelerated graphics for Windows 11 is now available on UTM for the first time. DirectX 11 is supported with DXMT and DirectX 12 is supported with D3DMetal (when available). The driver is still experimental and games compatibility is currently limited. See [Windows guest support]({% link guest-support/windows.md %}) for more details.
* **Vulkan 1.3 graphics support for Linux** Vulkan 1.3 is now supported on Linux guests with VirtIO Venus drivers in Mesa. Additionally, OpenGL 4.1 is supported with the new Apple Core OpenGL renderer backend (macOS only). See [Linux guest support]({% link guest-support/linux.md %}) for more details.
* **Snapshots** Save your VM at any point and go back to it later from the new [Snapshots]({% link advanced/snapshots.md %}) tab. You can save, overwrite, restore, rename, and delete snapshots. Works with QEMU VMs on macOS and iOS 26, and with Apple Virtualization VMs on macOS 27.
* **macOS 27**{: .label .label-green } **Apple Virtualization updates** Pass USB devices through to your VM, turn on Secure Boot for Linux, run a VM without saving changes, and let VMs talk to each other with new networking modes (macOS 26+).
* **iOS**{: .label .label-blue } **Better touch controls** Gestures respond immediately, with new middle-click and right/middle-drag actions and a new "Touch mode (drag to scroll)". The keyboard accessory bar has been redesigned to match the iOS 26 keyboard. Game controller Options and Home buttons can now be mapped.
* **iOS 27.1**{: .label .label-blue } **iPhone Duo** Fold your iPhone Duo like a laptop, and the bottom half becomes a keyboard or touchpad for your VM.
* **macOS**{: .label .label-green } **Scripting improvements** Snapshots, USB devices, and VLANs can be scripted, macOS VMs can be created and installed on the Apple backend, and the IP address of Apple VMs can be queried. `utmctl` gains `snapshot` and `discard-state` commands. See the updated [scripting reference]({% link scripting/reference.html %}).
* **iOS 26**{: .label .label-blue } **Disk tools on iOS** Reclaim Space, Compress, Resize, and converting imported drives to QCOW2 are now available on iOS.

## Notes
* Suspended VMs may not resume correctly after updating. We recommend shutting down all VMs before you update UTM.
* **macOS 12 and iOS 15** are the new minimum supported systems. Please use UTM v4.7.x if you are on an older version.
* We now have a [development blog](https://blog.getutm.app)! Follow us for in-depth technical deep dives such as how we brought DirectX to QEMU.
* **macOS**{: .label .label-green } To use the new graphics driver for Windows 11, we recommend a fresh install because the driver is still experimental and its use could lead to instability in the system. During the install of the guest tools, you will be prompted to select the experimental graphics driver. If you wish to install the new driver on a system that already is running the older display only driver, you need to run the uninstall script provided on the guest tools install ISO first.
* **macOS**{: .label .label-green } D3DMetal requires Rosetta on Apple Silicon. If Rosetta is not installed, UTM will fall back to DXMT (DirectX 11 only).
* **macOS**{: .label .label-green } The Apple Core OpenGL renderer backend does not support Vulkan or DirectX.
* KosmicKrisp is provided as an experimental Vulkan driver and requires macOS 26 or iOS 26. MoltenVK is the recommended driver.
* Linux desktop rendering in Vulkan does not work due to lack of support for indirect draws for geometry shaders. Please configure your guest to use the older VirGL Gallium driver.
* **macOS**{: .label .label-green } The snapshot scripting commands from v5.0.5 have been replaced by snapshot objects (`snapshots of vm`, `create snapshot`, `restore`, …). Scripts that use the old commands need updating.
* **macOS 27**{: .label .label-green } To pass a USB device through to an Apple Virtualization VM, first assign it to UTM from the "Virtual Machine Accessories" item in the menu bar.
* ARM64 QEMU VMs now always use GICv3, which improves performance. Previously this was only the case for more than 8 vCPUs.
